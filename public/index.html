HOW THE SCORE IS BUILT

Antares queries 5 independent data sources in parallel, runs 6 analysis layers and aggregates everything into a 0–1000 score. Each layer can contribute positive or negative points. A Safe Gate overrides any score: if a critical flag is raised, the token is blocked regardless of its numeric score.
