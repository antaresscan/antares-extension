# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Antares, please report it responsibly:

1. **Do NOT open a public issue.**
2. Email **security@antares.boo** with:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
3. You will receive a response within **48 hours**.
4. We will coordinate a fix and disclosure timeline with you.

## Scope

- Backend API (`/api/*`)
- Chrome extension content scripts
- Scoring engine and pipeline
- Rate limiting and authentication middleware

## Out of Scope

- Third-party API behavior (Helius, GoPlus, RugCheck, DexScreener)
- Browser-level vulnerabilities
