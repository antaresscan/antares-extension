# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x.x   | Yes       |

## Reporting a Vulnerability

1. **Do NOT open a public issue.**
2. Email **security@antares.boo** with description, steps to reproduce, and potential impact.
3. You will receive a response within **48 hours**.

## Scope

- Backend API (api/*)
- Chrome extension content scripts
- Scoring engine and pipeline
- Rate limiting and authentication middleware

## Out of Scope

- Third-party API behavior (Helius, GoPlus, RugCheck, DexScreener)
- Browser-level vulnerabilities
