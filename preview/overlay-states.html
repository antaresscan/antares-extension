Manual test plan — interactive states

The states above cover everything that's deterministic from buildResultNode. Three more behaviours need a real browser load to verify:

  • Watchlist · happy path — load extension, scan a SAFE token, click + Watch → button flips to ✓ Watching + green border, stays disabled.
  • Watchlist · limit reached — as Free user with 5 items already watched, click + Watch on a 6th → button shows Limit → PRO + red border; subsequent click opens https://antares-website.vercel.app/pricing in a new tab.
  • Quota cap — perform 50 scans in < 24h → 51st scan fails with HTTP 429, overlay disappears (existing rate-limit-handling path).
  • Pro tier flip — SET user:<your-install-id>:tier "pro" in Upstash directly, refresh a token page → quota badge becomes PRO, affiliate row hides.

All deterministic states (above) come from a single buildResultNode() call per variant using happy-dom, so any visual regression here will reproduce 1:1 in the live extension.
