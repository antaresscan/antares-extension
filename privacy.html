Privacy Policy

Last updated: April 8, 2025

1. Overview

Antares (“the Extension”) is a browser extension that scans Solana token pages for potential scam indicators. Your privacy is important to us. This policy explains what data we collect, how we use it, and your rights.

2. Data We Collect

Antares collects only the following data:

  • Solana token contract addresses detected on pages you visit (e.g. pump.fun, Raydium, Jupiter). These addresses are sent to our API to run security analysis.
  • No personal data is collected: no names, emails, wallet addresses, IP addresses, or browsing history.
  • No cookies or trackers are used.

3. How We Use Data

Token addresses are used exclusively to:

  • Query public blockchain APIs (GoPlus, RugCheck, Helius, DexScreener, Solscan) for security data.
  • Compute a risk score displayed in the extension popup.
  • Cache results temporarily (up to 5 minutes) to reduce API calls.

We do not sell, share, or monetize any data.

4. Third-Party APIs

The Extension sends token addresses to the following third-party services:

  • GoPlus Security API
  • RugCheck API
  • Helius RPC
  • DexScreener API
  • Solscan Public API

Each service has its own privacy policy. No user-identifiable information is included in these requests.

5. Data Storage

Antares does not store any data on your device beyond the default Chrome extension storage for user preferences (theme, settings). Server-side caching is ephemeral (max 5 minutes) and contains only token analysis results, not user data.

6. Permissions

The Extension requests the following Chrome permissions:

  • activeTab: To detect Solana token addresses on the current page.
  • storage: To save user preferences locally.

7. Children’s Privacy

Antares is not directed at children under 13. We do not knowingly collect data from children.

8. Changes

We may update this policy. Changes will be posted on this page with a revised date.
