# Backtest corpus: one Solana token mint per line.
# Lines starting with # and blank lines are ignored.
#
# Seed it by appending mints you want to backtest. The ingestion script
# (scripts/backtest/ingest.ts) reads this file twice in the lifecycle
# of an entry:
#   1. Once at scan time → produces an "initial" snapshot.
#   2. Once 7-90 days later → produces a "current" snapshot used to
#      derive ground truth.
#
# The two snapshots together form a CorpusEntry (see scripts/backtest/types.ts).
#
# Examples (kept commented so the file is non-empty but the ingest run
# is opt-in — uncomment to include in the next run):
# So11111111111111111111111111111111111111112
# EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v
