Support

Last updated: May 9, 2026 · Antares Chrome extension

1. Contact

The fastest way to reach us about the Antares extension is by email. We read every message and reply within 2 business days.

antaresantiscam@gmail.com

Please include the following so we can help quickly:

  • Extension version (visible in chrome://extensions → Antares → Details).
  • Browser and OS (e.g. Chrome 130 on Windows 11).
  • The trading site you were on when the issue occurred (DexScreener, Birdeye, Photon, etc.).
  • The token contract address, if applicable.
  • A short description of what you expected vs. what happened. Screenshots help.

2. Bug reports

If you've spotted a reproducible bug, email the address above with the steps to reproduce it. For non-sensitive issues you can also write directly to antaresantiscam@gmail.com with the subject line [BUG] followed by a one-line summary.

Security issues: please do not describe exploitable vulnerabilities by email. Use GitHub's Private Vulnerability Reporting flow described in our privacy policy (section 11) instead. Public disclosure before a fix puts users at risk.

3. Feature requests

We love hearing what you want next. Email us with the subject line [FEATURE] and describe the use case — not just the feature, but the problem you're trying to solve. Concrete examples (a token where the current verdict missed something, a trading site we don't yet support, etc.) make it much easier to prioritise.

4. Frequently asked questions

Why doesn't Antares show anything on my page?

Antares only injects on the 8 trading platforms listed in our manifest: DexScreener, Birdeye, Pump.fun, Photon, Axiom, GMGN, Telemetry, and GeckoTerminal. On any other site the extension is dormant by design. If you're on a supported site and still see nothing, refresh the page once — the content script attaches when the URL contains a Solana contract address.

The verdict says DANGER but the price is going up — is Antares wrong?

No. Antares scores structural risk (concentration, contract surface, LP burn status, holder distribution), not short-term price action. A token can pump while still being a coordinated dump risk. The Full Analysis page breaks down which specific layer triggered the verdict so you can decide for yourself.

Why does the same token sometimes give a different score?

Some inputs are real-time: liquidity, holder distribution, volume, and on-chain transfers all change as the token trades. The verdict reflects the state of the chain at scan time. If a critical wallet sells or LP gets pulled, the score moves accordingly.

Does Antares store my wallet address or trades?

No. Antares never reads your wallet, never reads form fields, never reads cookies. It extracts the public Solana contract address visible in the URL or DOM of supported pages and sends only that to our API. Read the privacy policy for the full data flow.

I'm getting "rate limited" errors. What's happening?

The free public API enforces a sliding-window rate limit so it stays fast for everyone. If you hit it, wait 60 seconds and try again. If you're consistently hitting the limit, email us — we can usually figure out what's going on.

Can I use Antares on Solana tokens that aren't on a DEX yet?

Partially. Pre-launch tokens (no liquidity yet) have no price/holder data, so several layers of the score will be inconclusive. Antares will still surface what it can read on-chain (mint authority, freeze authority, supply, deployer history) but the overall verdict is most reliable once the token is trading.

The overlay disappeared. How do I bring it back?

The overlay can be hidden via the Stealth toggle in the extension popup. Click the Antares icon in your browser toolbar and turn Stealth off. If that's not it, refresh the page once.

How do I report a token that Antares missed (false negative) or wrongly flagged (false positive)?

Email the address above with subject [VERDICT] and include the contract address plus what you observed on-chain. We use false negatives to tune the rug database and false positives to refine the scoring weights.
